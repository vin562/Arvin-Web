# Buku Kecil untuk Annisa

Isi folder ini:
- index.html : halaman buku
- music.mp3  : lagu latar (jangan ganti nama file ini)

Cara deploy ke GitHub Pages:
1. Buat repository baru di github.com (misalnya: buku-annisa), pilih Public.
2. Klik "uploading an existing file", lalu unggah index.html, music.mp3, dan README.md.
3. Klik Commit changes.
4. Buka Settings > Pages. Di bagian Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder / (root), lalu Save.
6. Tunggu 1 sampai 2 menit. Link buku: https://USERNAME.github.io/buku-annisa/
